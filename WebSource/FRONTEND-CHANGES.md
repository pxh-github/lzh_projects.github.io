# 运输调度前端与真实后端连接

页面由 Spring Boot 从 WebSource 提供，无需 npm 构建。访问实时监控 <http://localhost:9091/html/cycle.html> 和实验沙箱 <http://localhost:9091/html/sandbox.html>。启动、后端改造、容量边界与验证记录见 [BACKEND-CHANGES.md](../BACKEND-CHANGES.md)。

## 已连接业务

- 实时监控读取车辆、订单、任务、循环状态和 SQL 聚合指标，进入页面不会自动重置。
- 循环、动态新增、重置按钮调用真实后端。新增保持循环运行；重置取消旧动画和趋势样本。
- 地图沿用高德 SDK、车辆标记及路线动画。任务增量读取、轮询防重入；动画倍率只影响展示，后端按事件推进仿真时钟。
- 五项指标包含车辆等待分钟、空载公里、里程利用率、完成吨位和油耗模型碳排放估算。车辆详情使用后端全历史聚合。
- 沙箱通过 /sandbox 保存方案、提交真实 Run、读取进度、重跑、获取事件和比较结果，全部保存到 MySQL。
- Run 配置冻结，重跑读取旧 Run 的场景与参数。对比检查快照、种子及全部控制条件，仅算法可不同。
- 新 Run 完成后自动选为候选；页面轮询保留未保存参数。
- 当前载货、外部实时随机事件流等未接入字段明确标注。仿真路线、碳排放及事件使用简化模型。

## 车辆曲线行驶

实时监控新增行驶路线选择与“预览车辆路线”。已有多点道路轨迹保持原样；只有起点、取货点、终点的简略路线默认生成平滑曲线示意，用虚线和文字标识，也可切换回原始路线。路线绘制与车辆运动共用相同坐标，保留每个停靠点，并按地理距离分配动画进度；每帧通过二分查找定位路径段。

预览读取最近任务，仅播放6秒动画；预览结束恢复车辆位置，不执行派单。预览期间禁用启动，循环运行时禁用预览。重置可取消当前动画并移除旧路线。该改动不改变后端里程、成本、调度时间或数据库任务。

新增 js/services/route-geometry.js，cycle.html 在车辆脚本前加载它；cycle.js 使用曲线路径和预览控制。新增 tests/route-geometry.test.cjs 验证停靠点、真实道路保留、无效坐标、地理距离和极地/日期变更线边界。

最新前端测试合计14项通过；浏览器读取真实任务，验证65个曲线点、349帧位置更新、绘制路径一致、预览后位置恢复，未发出业务写入请求，未见脚本异常。原始路线切换有效，现有业务仍为52个任务、20个订单。地图底图和道路渲染仍依赖高德及浏览器环境。

## 2026-10-12 沙箱比较更新

比较区默认跟随当前方案的最新运行；点击历史运行、切换方案或提交新 Run 时同步候选及图表。无运行的新方案清空旧比较；排队、运行中、失败不显示旧候选指标。默认基准选择最近的同场景、同模型、同参数和同种子基准运行，找不到时留空。手动更改下拉框后保持历史对比，点击“跟随当前运行”恢复同步。记录按 startedAt 排序，避免数据库同秒创建记录的 UUID 排序误选旧结果。

相同配置重跑的结果可能一致；指标未变化不等于页面未刷新。页面对一致结果提供可复现说明，算法比较仍要求控制条件一致。服务模块新增 comparisonControl/comparisonPair，5 项回归测试覆盖旧记录、控制条件、不完整记录及未完成状态；前端合计22项通过。

真实验收创建独立方案“沙箱图表更新验收 2026-10-12”，10辆车、订单周期120分钟。种子222在24小时内无完成任务，五项完成指标为0；种子333完成6吨、空载1676.63km，图表同步变化。未修改原有方案和实时场景。详情见 ../reports/2026-10-12-沙箱比较修复.md。

## 2026-10-12 全部订单完成与时长指标

新实验取消24小时截止，结束条件改为“全部订单运输完成”。环境配置新增订单数量（1～1000，默认100）；订单生成周期控制有限订单的到达间隔。当前运行显示已完成订单数 / 总数、全部订单完成时长和平均订单完成时长，进度按完成订单比例更新。

沙箱独立使用七项指标：原有五项加“全部订单完成时长”“平均订单完成时长”，均以仿真小时显示，同条件下越低越好。两项同时进入比较图、表格、JSON及CSV导出，并附口径说明。平均值按订单计算，拆单运输取该订单最后一批完成时间；实时监控的五项指标保持独立口径。

历史24小时 Run 显示旧口径说明，缺少的时长显示“—”；重跑按钮禁用并提示开始新实验。对旧方案重新开始会使用全部订单完成的新模型，历史数据保持不变。新旧模型不同的运行不展示可归因于算法的改善率。

最新验证为24项前端测试通过，真实后端完成种子222的12个订单，两种算法均运输182.4吨。页面显示七张比较图和七行指标，导出包含两项时长；刷新及后端重启后结果恢复，浏览器无脚本异常，390px手机布局无横向溢出。完整验收见 ../reports/2026-10-12-全订单完成改造.md。
