# 实验方案删除功能

## 使用方法

1. 重启后端，在浏览器刷新数据实验沙箱页面。
2. 在左侧选择待删除的实验方案。
3. 点击顶部“删除实验方案”，核对确认框中的方案名称。
4. 确认后，方案及其全部运行历史、结果和事件一并永久删除。

排队或运行中的方案暂不能删除，需等待执行结束。删除后自动选择相邻方案，并更新运行历史、比较选项和导出按钮。删除最后一个方案后保留空列表，重新打开页面也不会自动创建新方案；点击“新建实验”即可继续使用。

## 数据处理

新增 `DELETE /sandbox/experiments/{id}`，请求体为 `{"version":1}`，版本号使用打开该方案时读到的版本。方案已被其他页面修改时返回409，要求刷新确认；方案不存在时返回400。

删除方案与其运行记录在同一数据库事务中完成。提交运行和删除方案均先锁定对应方案行，防止并发提交产生孤立记录。后端独立查询全部关联记录，存在排队或运行状态时拒绝删除；前端同时禁用按钮。

场景快照可能被复制方案共用，因此删除方案时保留快照。其他方案及其运行历史不受影响。

## 验证范围

- 前端验证取消确认、删除后切换方案、比较项清理、删除最后一个方案、空列表重新进入、活动运行禁用、后端冲突提示和请求版本传递。
- 独立临时 MySQL 数据库验证空方案删除、完成及失败历史清理、共享场景与其他方案保留、旧版本冲突、活动运行拒绝及删除与提交并发。测试结束自动清理测试库。
- 后端共44项测试，43项通过，1项绑定旧模型的历史审计按原配置跳过；其中独立 MySQL 集成测试14项全部通过。构建输出见 `tmp/delete-feature-tests.log`。
- 前端33项测试全部通过，两个修改脚本的语法检查通过。测试未对用户现有实验方案执行删除。
